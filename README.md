# OneDrop AI 🩸

## About the Project
OneDrop AI is an AI-powered blood donation system that helps people find blood donors and submit blood requests.

## Features
- Donor Registration
- Search Donors by Blood Group and City
- Blood Request Form
- AI Chatbot using Ollama
- Flask Web Application
- SQLite Database

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- Ollama AI

## How It Helps
OneDrop AI makes it easier to connect people who need blood with potential donors.
